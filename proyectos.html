Proyectos

1. Sistema de Gestión de Inventarios

Desarrollo de una aplicación web para administrar productos, registrar entradas y salidas de inventario y generar reportes de control. El sistema permite a los usuarios gestionar información de forma rápida y organizada.

Tecnologías:

HTML, CSS, JavaScript, Node.js, MySQL

2. Plataforma de Reservas en Línea

Aplicación web que permite a los usuarios reservar servicios en línea, gestionar horarios y recibir confirmaciones automáticas. El sistema incluye autenticación de usuarios y panel de administración.

Tecnologías:

JavaScript, Node.js, Express, MongoDB

3. Sistema de Gestión de Biblioteca

Sistema diseñado para administrar libros, usuarios y préstamos dentro de una biblioteca. Incluye funciones de búsqueda, registro de préstamos y control de devoluciones.

Tecnologías:

Java, MySQL

4. Aplicación de Portafolio Web Personal

Desarrollo de un sitio web personal para mostrar información profesional, habilidades, proyectos y experiencia en el área de desarrollo de software.

Tecnologías:

HTML, CSS, JavaScript

5. API para Gestión de Usuarios

Desarrollo de una API REST que permite registrar, autenticar y administrar usuarios dentro de una plataforma web, facilitando la integración con diferentes aplicaciones.

Tecnologías:

Node.js, Express, MongoDB
